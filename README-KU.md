# بەنزین خانە (GitHub Pages + Firebase Realtime Database)

ئەپەکە لەسەر GitHub Pages بڵاو دەکرێتەوە و داتاکان لە **Realtime Database** هەڵدەگیرێن. بێ ئیمەیل و پاسۆرد: کلیلێک لە Rules دادەنێیت، و هەر مۆبایلێک یەک جار هەمان کلیل دەنووسێت.

## شەفتەکان

شەفت بە دوگمەی **«داخستنی شەفت»** دادەخرێت (کۆتایی بەشی «خوێندنەوە»)، نەک بە کاتژمێر. هەر کاتێک حساباتەکەت تەواو بوو دایدەخەیت:
- ژمارەی کۆتایی هەر پەمپێک دەبێتە سەرەتای شەفتی دواتر.
- ئاستی تانکەکان دەگوازرێنەوە.
- نرخی ئێستا دەگوازرێتەوە. گۆڕینی نرخ لە شەفتێکدا شەفتە داخراوەکان ناگۆڕێت.

## ١. Firebase

1. https://console.firebase.google.com ← **Add project**.
2. **Build ← Realtime Database ← Create Database**، شوێنێک هەڵبژێرە (بۆ نموونە Belgium)، و **Locked mode** هەڵبژێرە.
3. تابی **Rules**: ناوەڕۆکی فایلی `database.rules.json` دابنێ. لە هەردوو دێڕەکەی `KEY-HERE-CHANGE-ME` بکە بە **کلیلەکەی خۆت** (لانیکەم ٨ پیت یان ژمارە، بە ئینگلیزی، بێ نیشانەی `/` و `.` و `$` و `#` و `[` و `]`)، پاشان **Publish**.
4. **Project settings** (ددان) ← **Your apps** ← ئایکۆنی `</>` ← **Register app**. ئەو `firebaseConfig`ـە کۆپی بکە و لە `firebase-config.js` جێگەی `PASTE_HERE`ـەکان بگۆڕە. `databaseURL` لە سەرەوەی Realtime Database دەبینرێت.

## ٢. GitHub

1. ڕیپۆزتریەکی نوێ دروست بکە (**Public** بۆ GitHub Pages بەخۆڕایی).
2. فایلەکان ڕاستەوخۆ لە ڕیشەی ڕیپۆزتری دابنێ: `index.html`, `app.js`, `style.css`, `firebase-config.js`, `.nojekyll`. (`database.rules.json` **مەیخە GitHub**، چونکە کلیلەکەی تێدایە.)
3. **Settings ← Pages ← Deploy from a branch ← main / (root) ← Save**.
4. دوای ١-٢ خولەک ئادرێسەکە دەردەکەوێت: `https://ناوی-تۆ.github.io/ناوی-ڕیپۆ/`. لەسەر مۆبایلەکان بیکەرەوە و **Add to Home screen** بکە.

## ٣. یەکەم جار

1. کلیلەکە بنووسە (هەمان ئەوەی لە Rules). تەنها یەک جار لەسەر هەر مۆبایلێک.
2. شاشەی ڕێکخستنی سەرەتایی: نرخەکان و ژمارەی ئێستای ١٥ میتەر و ئاستی ٦ تانک بنووسە.

## تێبینی

- **کلیل:** ئەگەر کلیلەکە هەڵە بێت، Firebase هیچ داتایەک نادات. هەرکەسێک کلیلەکە بزانێت دەتوانێت داتاکان ببینێت و بیگۆڕێت، بۆیە لە GitHub مەینووسە و تەنها بیدە بە دوو کارمەندەکەی تر. بۆ گۆڕینی کلیل: هەم لە Rules هەم لە ئەپەکە (دوگمەی «گۆڕینی کۆد»)، بەڵام داتای کۆن لەژێر کلیلی کۆندا دەمێنێتەوە.
- **ئینتەرنێت:** Realtime Database لەسەر وێب داتای ئۆفلاین هەڵناگرێت. ئەگەر ئینتەرنێت بڕا نیشانەی «ئۆفلاین» دێت، و ئەوەی نووسیوتە دوای گەڕانەوە دەنێردرێت تەنها ئەگەر لاپەڕەکە نەبەستیت.
- **پاشەکەوت:** لە Firebase Console ← Realtime Database ← ⋮ ← **Export JSON** دەتوانیت کۆپییەک بگریت.
